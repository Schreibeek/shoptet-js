# shoptet-js

Vlastní skripty pro e-shopy na Shoptetu, běží přes GitHub Pages (https://schreibeek.github.io/shoptet-js/...).

- lederer.js - lukaslederer.cz, načítá se v zápatí Shoptetu. Po změně zvednout ?v= v odkazu v HTML kódech (patička), jinak se může až 10 minut načítat stará verze. Na konci jsou doplňky vzhledu podle design systému v2 (dřív lederer-test.js).
- backup/puvodni-vzhled-2026-11-03/lederer.js - původní verze před přepnutím na nový vzhled.

Testovací vzhled (?lltest=1) skončil 3. 11. 2026 přepnutím nového vzhledu pro všechny. Přepínač, štítek i odebírání emoji skriptem jsou pryč, emoji jsou odebrané přímo v administraci.
